# Datasets

We evaluate with **three public, anonymized essay corpora** plus **synthetic essays with known flaws**, **for evaluation only**. They measure how closely our feedback matches human expert raters and whether it catches problems we know are there. They are not used to train anything, and none of the public essays are shipped in the app or committed to this repo.

| Dataset | Use it for | What it gives us | Size | License | Download |
|---|---|---|---|---|---|
| **ELLIPSE** (from Kaggle "Feedback Prize – English Language Learning") | **Accuracy evaluation**: grammar and coherence scores | Human scores for cohesion, syntax, vocabulary, phraseology, grammar, conventions | 3,911 essays (train split) ✅ downloaded | CC BY-NC-SA 4.0 | Automatic (GitHub) |
| **PERSUADE 2.0** (from Kaggle "Feedback Prize – Evaluating Student Writing") | **Argument feedback** (argument-structure eval) + main holistic benchmark | Argumentative essays labeled with discourse elements (Lead, Position, Claim, Counterclaim, Rebuttal, Evidence, Concluding Statement) + holistic scores | 25,996 essays, 285,383 annotations ✅ downloaded | CC BY-NC-SA 4.0 | Kaggle (login) |
| **ASAP 2.0** (successor to the Hewlett ASAP) | Secondary holistic check (source-based essays) | Essays with holistic scores 1–6 | 24,728 essays ✅ downloaded | CC BY 4.0 | Kaggle (login) |
| **Synthetic essays** | **Error and flaw detection** | Essays written to order with planted grammar errors and structural flaws (e.g. missing counterargument), so the right answer is known | 10 essays (2 hand-written + 8 generated by the LLM) | Project-authored | `python -m eval.generate_synthetic` |

## Download and prepare

```bash
python data/download_datasets.py      # downloads what it can, then runs prepare_datasets.py
python data/prepare_datasets.py       # unpacks Kaggle zips + builds derived files (safe to re-run)
```

- **ELLIPSE** downloads straight from the authors' public GitHub repo. No account needed.
- **PERSUADE 2.0 and ASAP 2.0** come from Kaggle. Either:
  - **manually** (easiest): open each Kaggle page, click **Download**, drop the zip(s) into `data/raw/` (keep Kaggle's names, e.g. `archive.zip`, `archive (1).zip`), then run `python data/prepare_datasets.py`; or
  - **with the Kaggle CLI:** run `pip install kaggle`, then put your API token in `~/.kaggle/kaggle.json` (Kaggle → Settings → API → Create New Token), then run `python data/download_datasets.py`.

`prepare_datasets.py` finds the files inside any zip in `data/raw/`, extracts only what we need, and streams the 804 MB annotation file without unpacking it. The result looks like this:

```
data/raw/                                   (git-ignored, excluded from Vercel)
  ellipse_train.csv                         ELLIPSE train split (3,911 essays)
  persuade_2.0/
    persuade_2.0_human_scores_demo_id_github.csv   PERSUADE essays + holistic scores (25,996 rows)
    sources.csv                             source articles for text-dependent prompts
    discourse_summary.csv                   built: expert-annotated argument elements per essay
  asap_2.0/
    ASAP2_train_sourcetexts.csv             ASAP 2.0 essays + scores (24,728 rows)
  archive.zip, archive (1).zip              the Kaggle downloads (can be deleted after prepare)
```

## ELLIPSE Corpus

*English Language Learner Insight, Proficiency and Skills Evaluation*

- **Kaggle:** https://www.kaggle.com/datasets/mpware/ellipse-corpus
- **Original source:** https://github.com/scrosseye/ELLIPSE-Corpus
- **Origin:** released through the Kaggle competition **"Feedback Prize – English Language Learning"** (https://www.kaggle.com/competitions/feedback-prize-english-language-learning). That competition's `train.csv` also works with our loader. It has lowercase columns and no `Overall` score, so only grammar and coherence are compared.
- **License:** CC BY-NC-SA 4.0 (Attribution-NonCommercial-ShareAlike), https://creativecommons.org/licenses/by-nc-sa/4.0/
- **Contents:** about 6,500 essays by English-language learners in grades 8–12, on 40+ prompts (cell phone policy, four-day school week, online vs. in-person classes, ...). Each essay has a holistic proficiency score plus six analytic scores. Includes anonymized demographics (gender, grade, race/ethnicity, economic status).
- **File we use:** `ELLIPSE_Final_github_train.csv`, saved as `data/raw/ellipse_train.csv`. The Kaggle mirror's `ELLIPSE_Final_github.csv` also works; the loader keeps only rows where `set == train`.
- **Columns** (verified from the file):
  `text_id_kaggle, full_text, gender, grade, race_ethnicity, num_words, num_words2, num_words3, num_sent, num_para, num_word_div_para, MTLD, TTR, Type, Token, task, SES, prompt, Overall, Cohesion, Syntax, Vocabulary, Phraseology, Grammar, Conventions, set`
- **Score scale:** 1.0–5.0 in steps of 0.5 (the average of two expert raters).
- **How we use it:** `python -m eval.run_eval ellipse`

  | Our score | ELLIPSE column |
  |---|---|
  | `grammar` | `Grammar` |
  | `coherence` | `Cohesion` |
  | `overall` | `Overall` |

- **Cite:** Crossley, S. A., Tian, Y., Baffour, P., Franklin, A., Kim, Y., Morris, W., Benner, B., Picou, A., & Boser, U. (2023). Measuring second language proficiency using the English Language Learner Insight, Proficiency and Skills Evaluation (ELLIPSE) Corpus. *International Journal of Learner Corpus Research, 9*(2), 248–269. Preprint: https://zenodo.org/records/11217937

## PERSUADE 2.0 Corpus

- **Kaggle:** https://www.kaggle.com/datasets/nbroad/persaude-corpus-2 (the "persaude" spelling in the URL is the uploader's)
- **Original source:** https://github.com/scrosseye/persuade_corpus_2.0 (The Learning Agency Lab + Vanderbilt University)
- **Origin:** the discourse-element annotations (PERSUADE 1.0) were the data for the Kaggle competition **"Feedback Prize – Evaluating Student Writing"** (https://www.kaggle.com/competitions/feedback-prize-2021). Version 2.0 adds holistic scores and covers all essays.
- **Why it fits argument feedback:** every Claim, Counterclaim, Rebuttal and Evidence span is labeled by experts, so we know whether an essay contains a counterargument and how strong its argument is.
- **License:** CC BY-NC-SA 4.0, https://creativecommons.org/licenses/by-nc-sa/4.0/
- **Contents:** 25,000+ argumentative essays by US students in grades 6–12, written for 15 prompts across two tasks (independent and source-based). Each essay has a holistic score, and every discourse element is annotated: Lead, Position, Claim, Counterclaim, Rebuttal, Evidence, Concluding Summary. Annotations were double-blind with full adjudication.
- **Files in the Kaggle zip (`archive.zip`, 55 MB):**
  - `persuade_2.0_human_scores_demo_id_github.csv` (76 MB): one row per essay.
  - `persuade_corpus_1.0.csv` (804 MB): one row per annotated span: 285,383 spans over all 25,996 essays. We condense it into `discourse_summary.csv`.
  - `sources.csv` (12 rows): title, author, URL and a GPT-4 summary of each source article.
- **Columns** (verified):
  - Essays: `essay_id_comp, full_text, holistic_essay_score, word_count, prompt_name, task, assignment, source_text, gender, grade_level, ell_status, race_ethnicity, economically_disadvantaged, student_disability_status`
  - Annotations: `essay_id_comp, competition_set, full_text, discourse_id, discourse_start, discourse_end, discourse_text, discourse_type, discourse_type_num`
- **Facts from profiling:**
  - 25,996 rows, but 4 essay IDs are duplicated. The loader keeps the first of each.
  - 15 prompts. `task` is **Independent** (13,118 essays, no source article) or **Text dependent** (12,875; students write about an article).
  - Scores (independent essays): 1: 82 · 2: 1,986 · 3: 3,758 · 4: 4,104 · 5: 2,457 · 6: 731.
  - Grades 6–12 (mostly grades 8 and 10); 2,244 essays by English-language learners.
  - Share of essays where experts annotated each element:
    - Position 98%
    - Claim 96%
    - Evidence 100%
    - Concluding Statement 85%
    - Lead 58%
    - **Counterclaim 29%**
    - **Rebuttal 23%**
- **Score scale:** holistic score 1–6.
- **How we use it:**
  1. **Argument structure:** `python -m eval.run_eval argument`. For each essay, our feedback marks which of the 7 elements it contains, and we compare that with the expert annotations. The sample is half essays with a counterclaim and half without, so detecting a **missing counterargument** gets a fair test.
  2. **Holistic agreement:** `python -m eval.run_eval holistic --dataset persuade`. Compares our overall and argument scores with the human 1–6 score, on a sample spread evenly across score levels. It uses **Independent essays by default**, because our app never sees the source article a Text-dependent essay is about. Each essay is sent with its real `assignment` text and the student's level (grade 6–8 = middle school, 9–12 = high school, English learner if `ell_status = Yes`).
- **Cite:** Crossley, S. A., Baffour, P., Tian, Y., Franklin, A., Benner, M., & Boser, U. (2024). A large-scale corpus for assessing written argumentation: PERSUADE 2.0. *Assessing Writing, 61*. Preprint: https://zenodo.org/record/8221504

## ASAP 2.0 (Automated Student Assessment Prize)

- **Kaggle:** https://www.kaggle.com/datasets/lburleigh/asap-2-0
- **Related competition:** https://www.kaggle.com/competitions/learning-agency-lab-automated-essay-scoring-2 (The Learning Agency Lab + Vanderbilt University, 2024)
- **Predecessor, the original ASAP (Hewlett Foundation):** https://www.kaggle.com/competitions/asap-aes. This was the classic automated-essay-scoring benchmark: 8 prompts, grades 7–10, each prompt with its own score range. We use ASAP 2.0 instead because it is larger and more recent, and uses one 1–6 holistic scale across all prompts, so scores compare directly.
- **License:** CC BY 4.0 (Attribution), https://creativecommons.org/licenses/by/4.0/
- **Contents:** about 24,000 argumentative essays by US students, aligned to current standards, sampled across economic and geographic populations to reduce bias, with holistic scores.
- **File we use:** `ASAP2_train_sourcetexts.csv` (208 MB, in the Kaggle zip `archive (1).zip`), extracted to `data/raw/asap_2.0/`.
- **Columns** (verified): `essay_id, score, full_text, assignment, prompt_name, economically_disadvantaged, student_disability_status, ell_status, race_ethnicity, gender, source_text_1, source_text_2, source_text_3, source_text_4`
- **Facts from profiling:**
  - 24,728 essays on 7 prompts. **All of them are source-based**: students write about one to four articles, given in `source_text_1..4`.
  - Scores: 1: 1,751 · 2: 6,847 · 3: 9,021 · 4: 5,553 · 5: 1,356 · 6: 200.
  - 3,276 essays by English-language learners. No grade column.
  - **51% of ASAP 2.0 essays (12,724) also appear in PERSUADE 2.0, with identical scores.** The roughly 12,000 essays unique to ASAP are all source-based (Driverless cars, Exploring Venus, Facial action coding, Face on Mars, Cowboy).
  - The source texts contain some broken characters (`�`, an encoding issue in the original data). We don't use the source texts.
- **Score scale:** holistic score 1–6.
- **How we use it:** `python -m eval.run_eval holistic --dataset asap` is a **secondary check** on source-based writing. Our app judges these essays without seeing the article, so expect lower agreement, and say so if you report the number. **PERSUADE's independent essays are the main holistic benchmark.**
- **Cite:**
  - Crossley, S. A., Baffour, P., Burleigh, L., & King, J. (in press). A large-scale corpus for assessing source-based writing quality: ASAP 2.0. *Assessing Writing.* https://www.sciencedirect.com/science/article/pii/S1075293525000418
  - Crossley, S., Baffour, P., King, J., Burleigh, L., Reade, W., & Demkin, M. (2024). Learning Agency Lab – Automated Essay Scoring 2.0. Kaggle. https://kaggle.com/competitions/learning-agency-lab-automated-essay-scoring-2

## Synthetic essays (project-authored)

Public datasets only tell us whether our **scores** match humans. To check that the feedback **catches specific problems**, we use essays where we planted the problems ourselves, so the right answer is known.

**How they're made**
- `eval/synthetic_cases.json`: 2 hand-written essays.
  - `libraries_planted_10`: 10 planted grammar and mechanics errors.
  - `garden_structural_flaws`: 4 planted errors, plus no counterargument, no conclusion and a cliché opening.
- `eval/generate_synthetic.py`: has the LLM (Gemini, or Groq as backup) write **8 more** essays to a precise spec (topic, student level, number of planted errors, structural flaws). The model returns the exact text of each planted error, and we keep only errors whose quote really appears in the essay. Output goes to `eval/synthetic_generated.json`. **Read the generated essays once by eye** before trusting the numbers.
  ```bash
  python -m eval.generate_synthetic      # needs the real API; one call per essay
  ```

**What the 8 generated essays cover**

| Essay | Level | Planted errors | Structural flaws |
|---|---|---|---|
| Homework optional? | English learner | 10 | none |
| Car-free downtowns | High school | 5 | missing counterargument |
| Voting age 16 | High school | 0 | missing evidence, clichés |
| Four-day school week | Middle school | 8 | no conclusion |
| AI and creativity | Undergraduate | 4 (subtle) | weak/unclear thesis |
| School uniforms | High school | 5 | off-topic paragraph, no transitions |
| Online vs in-person classes | English learner | 8 | missing counterargument, missing evidence |
| Free museums (**control**) | High school | 0 | none (should score high) |

**How they're scored** (`python -m eval.run_eval synthetic`)
- **Error recall:** a planted error counts as caught if any flagged correction overlaps its text.
- **Structural flaw recall:** a flaw counts as caught if the improvement comments for the relevant criterion mention it. For example, a missing counterargument counts if the argument feedback mentions "counterargument", "opposing view", "rebut", and so on. The keywords are in `eval/flaws.py`.
- **False-alarm rate:** how often each flaw is "detected" in essays that **don't** have it. This keeps the keyword check honest.
- **Control essay:** a flawless essay should get high scores and no invented problems.

## Compliance notes

- **No personal data.** All three corpora are anonymized by their publishers. We don't use their demographic columns.
- **Non-commercial.** ELLIPSE and PERSUADE are licensed CC BY-NC-SA, which is fine for a hackathon prototype and research evaluation. Any commercial version would need to drop them or get permission.
- **Attribution.** The citations above should appear in our docs (`docs/AI_APPROACH.md`) and be mentioned in the demo whenever we show eval results.
- **No redistribution.** Raw files stay in `data/raw/` (git-ignored). Model outputs for dataset essays are cached in `eval/cache/` (git-ignored), never in the committed `data/cache/`.
- **Sending essays to the model API.** During evaluation, essays from these corpora are sent to the free Gemini or Groq API to be scored. Only the essay text and assignment prompt are sent, never any metadata. The free Gemini tier may use inputs to improve Google's products. The corpora are already public and anonymized, so this is acceptable, but don't send real students' essays to a free tier.
